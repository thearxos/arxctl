App isolation · arxonion
Run apps in a Tor-only namespace

Stronger than the transparent proxy above: an isolated app runs in a network namespace whose only route is Tor, so it cannot see or reach your real IP even if it is fully compromised (a browser exploit, malware). This is the structural guarantee, applied per-app so ArxOS stays a daily driver.

What this does and does not do — honestly. Everything you launch from the isolated mode (the terminal here, and browsers you start with it) is routed through Tor, comprehensively, until you switch it off. It does not retroactively route already-open windows or background services — doing that would mean moving your whole login session into the namespace, which is heavy and can lock you out of your desktop. The daily-driver-correct trade is: isolate what you launch here, keep the rest of the system normal. Requires anond/Tor running; it fails closed (an isolated app simply cannot connect) if Tor is down.
